| D-015 | 2026-11-25 | Footprint conventions. Bars are aligned to UTC epoch multiples. The ladder includes untraded buckets inside the bar range as 0. | D-016 | 2026-11-25 | Profile conventions. Rows have size `tpo_tick`. POC = row midpoint, VAH = upper edge of the top row, VAL = lower edge of the bottom row. TPO counts 30-min periods per row from 1m high/low.
